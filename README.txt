FIR SECTION SUGGESTION SYSTEM — CONNECTED FRONTEND DEMO

FILES
- index.html: Login and account registration page
- auth.css / auth.js: Authentication page styles and demo logic
- dashboard.html: Incident analysis dashboard
- dashboard.css / dashboard.js: Dashboard styles and logic

HOW TO RUN
1. Extract the ZIP file into a folder.
2. Open index.html in a browser.
3. Choose Create account, register a demo account, then log in.
4. Successful login opens dashboard.html.
5. Click Log out to return to the login page. Directly opening dashboard.html without a demo session redirects to index.html.

IMPORTANT
This is an academic frontend-only demonstration. Account data and demo session are stored in browser localStorage; passwords are not securely hashed. Do not use real passwords or confidential case information. Client-side checks are not real security. A production application requires a backend, secure password hashing, server-managed sessions, access control, and secure storage.
